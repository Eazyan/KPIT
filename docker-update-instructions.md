# Инструкции по обновлению Docker контейнера

После внесения изменений в код необходимо обновить Docker контейнер для применения этих изменений. Выполните следующие шаги:

## 1. Найдите ID контейнера с сервером FastAPI

```bash
docker ps
```

Найдите в списке контейнер с именем, содержащим `fastapi-server` или `backend`.

## 2. Скопируйте обновленные файлы в контейнер

```bash
# Копирование файла routes/grades.py
docker cp fastapi-server/app/api/routes/grades.py CONTAINER_ID:/app/app/api/routes/grades.py

# Копирование файла services/grades/grade_service.py
docker cp fastapi-server/app/services/grades/grade_service.py CONTAINER_ID:/app/app/services/grades/grade_service.py
```

## 3. Перезапустите контейнер

```bash
docker restart CONTAINER_ID
```

## 4. Обновите клиентскую часть (если необходимо)

Если вы вносили изменения в клиентскую часть (файлы в директории `client`), выполните:

```bash
# Если вы используете docker-compose
docker-compose up -d --build client
```

## 5. Проверка работоспособности

После перезапуска проверьте, что все функции работают корректно:

- Добавление оценок работает
- Отображение оценок у студента работает
- Удаление оценок работает корректно (удаляется только выбранная оценка)
- Типы оценок корректно отображаются
- Цветовая схема оценок применяется правильно

## Примечание

Если вы используете docker-compose для управления всеми контейнерами, альтернативно можно перезапустить все сервисы:

```bash
docker-compose down
docker-compose up -d
```

Это полностью пересоздаст контейнеры с учетом всех изменений в коде.
