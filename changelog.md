# Журнал изменений системы оценок

## Серверная часть

### 1. Исправления в работе с курсорами MongoDB

- Добавлены `await` перед вызовами `grades_collection.find` в методах:
  - `get_student_grades`
  - `get_student_grade_summary`
  - `get_discipline_grades`
  - `get_discipline_grade_stats` 
  - `get_student_grades_by_discipline` (добавлен await перед aggregate)

### 2. Улучшения в обработке дат

- Добавлена поддержка разных форматов даты при добавлении оценки:
  - ISO формат
  - Формат YYYY-MM-DD
  - Текущая дата, если дата не указана
- Улучшена обработка даты в ответах API, чтобы предотвратить ошибки при конвертации

### 3. Изменен метод удаления оценок

- Создан новый API эндпоинт `/grades/{grade_id}` для удаления конкретной оценки по её ID
- Добавлены проверки для обеспечения доступа только авторизованных преподавателей
- Устранена ошибка, когда удалялись все оценки студента вместо одной

### 4. Улучшения в методе добавления оценок

- Добавлена поддержка типа "lab" (лабораторная работа)
- Автоматическое создание связи между группой студента и дисциплиной при добавлении оценки
- Расширен ответ API при добавлении оценки, теперь включает ID, значение и тип оценки

### 5. Переработан метод получения оценок студента по дисциплине

- Реализована полноценная агрегация с MongoDB для получения дополнительных данных о дисциплине и преподавателе
- Добавлена поддержка фильтрации оценок по датам (from_date, to_date)
- Улучшена сортировка оценок (по дате, в обратном порядке)

## Клиентская часть

### 1. Обновлен метод удаления оценок

- Метод `deleteGrade` теперь использует ID оценки вместо ID студента и дисциплины
- Добавлены дополнительные проверки перед удалением, чтобы избежать ошибок
- Улучшено сообщение подтверждения, теперь показывает значение и тип оценки

### 2. Улучшение отображения оценок

- Обновлена цветовая схема для оценок:
  - 5 - зеленый (#4caf50)
  - 4 - светло-зеленый (#8bc34a)
  - 3 - желтый (#ffeb3b)
  - 2 - оранжевый (#ff9800)
  - 1 - красный (#f44336)
- Добавлено отображение типа оценки рядом с её значением

### 3. Расширены типы оценок

- Добавлена поддержка типа "Лабораторная работа"
- Улучшено отображение типов оценок в интерфейсе

## Обработка ошибок

- Улучшены сообщения об ошибках для более понятной диагностики проблем
- Добавлено ведение более подробных логов для отладки
- Проверки прав доступа для операций с оценками

## Итог

После внесенных изменений система оценок должна работать корректно:
- Преподаватели могут добавлять, редактировать и удалять отдельные оценки
- Студенты видят свои оценки в журнале и аналитике
- Оценки правильно отображаются с учетом их типа и имеют интуитивно понятную цветовую схему
- Устранены проблемы с удалением всех оценок вместо одной
- Исправлены ошибки с асинхронной обработкой запросов к MongoDB
