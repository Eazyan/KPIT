# КПиУС (Система контроля посещаемости и успеваемости студентов)

Демонстрационная версия системы контроля посещаемости и успеваемости студентов для ДВФУ. Проект реализован с использованием современных технологий веб-разработки, в том числе React с TypeScript, FastAPI и MongoDB.

## Структура проекта

Проект разделен на два основных компонента:

- `client` - фронтенд приложения на React с TypeScript и Material UI в стиле Vision OS
- `fastapi-server` - бэкенд API на FastAPI и MongoDB

## Быстрый старт с Docker

Проект полностью контейнеризирован и может быть запущен с помощью Docker.

### Предварительные требования

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

### Запуск проекта

Для удобства использования в проекте предусмотрены скрипты для запуска:

#### Linux/macOS
```bash
# Запуск в режиме разработки (с горячей перезагрузкой)
./start.sh dev

# Запуск в режиме продакшена
./start.sh prod

# Остановка контейнеров
./start.sh down

# Просмотр логов
./start.sh logs

# Перезапуск контейнеров
./start.sh restart
```

#### Windows (Batch)
```cmd
# Запуск в режиме разработки (с горячей перезагрузкой)
start.bat dev

# Запуск в режиме продакшена
start.bat prod

# Остановка контейнеров
start.bat down

# Просмотр логов
start.bat logs

# Перезапуск контейнеров
start.bat restart
```

#### Windows (PowerShell)
```powershell
# Запуск в режиме разработки (с горячей перезагрузкой)
.\start.ps1 dev

# Запуск в режиме продакшена
.\start.ps1 prod

# Остановка контейнеров
.\start.ps1 down

# Просмотр логов
.\start.ps1 logs

# Перезапуск контейнеров
.\start.ps1 restart
```

После запуска в режиме разработки:
- Клиентское приложение будет доступно по адресу: http://localhost:3000
- API сервер будет доступен по адресу: http://localhost:5005
- MongoDB будет доступна по адресу: localhost:27017

После запуска в режиме продакшена:
- Приложение будет доступно по адресу: http://localhost

## Ручная установка и запуск (без Docker)

### Подготовка

1. Убедитесь, что у вас установлены Node.js (v14+), npm и Python 3.9+
2. Установите MongoDB локально или используйте удаленную базу данных

### Запуск сервера

```bash
cd fastapi-server
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
venv\Scripts\activate     # Для Windows
pip install -r requirements.txt
python run.py
```

Сервер запустится на порту 5005.

### Запуск клиента

```bash
cd client
npm install
npm start
```

Клиентское приложение будет доступно по адресу http://localhost:3000.

## План рефакторинга

В рамках глобального рефакторинга планируются следующие улучшения проекта:

### Серверная часть (Backend)
1. **Оптимизация API маршрутов**:
   - Рефакторинг длинных обработчиков маршрутов с выносом логики в сервисные функции
   - Удаление дублирующихся эндпоинтов и объединение схожей функциональности
   - Стандартизация формата ответов API

2. **Улучшение структуры базы данных**:
   - Оптимизация схем моделей
   - Добавление индексов для повышения производительности
   - Улучшение валидации входных данных

3. **Улучшение безопасности**:
   - Усиление проверок аутентификации и авторизации
   - Рефакторинг JWT механизма с добавлением refresh-токенов
   - Улучшение логирования безопасности

4. **Оптимизация производительности**:
   - Кэширование часто запрашиваемых данных
   - Оптимизация запросов к базе данных
   - Асинхронная обработка тяжелых операций

### Клиентская часть (Frontend)
1. **Рефакторинг компонентной структуры**:
   - Выделение переиспользуемых компонентов
   - Улучшение организации файлов и папок
   - Внедрение единой системы стилей

2. **Оптимизация производительности**:
   - Мемоизация компонентов и функций
   - Ленивая загрузка компонентов
   - Оптимизация повторных рендеров

3. **Улучшение обработки ошибок и состояний загрузки**:
   - Единый подход к обработке ошибок API
   - Скелетон-загрузка для улучшения UX
   - Добавление механизма повторных попыток для неудачных запросов

4. **Улучшение пользовательского интерфейса**:
   - Повышение доступности (accessibility)
   - Улучшение адаптивности для мобильных устройств

### Тестирование и документация

   - Интеграционные тесты для ключевых бизнес-процессов

2. **Расширение документации**:

   - Добавление документации по развертыванию
   - Создание руководства по разработке

### Инфраструктура
1. **Оптимизация Docker-контейнеров**:
   - Уменьшение размера образов
   - Улучшение конфигурации для разработки и продакшена
   - Оптимизация многоступенчатой сборки

2. **Настройка CI/CD**:
